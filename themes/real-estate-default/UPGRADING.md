# Upgrading

## From pre-release builds to 1.0.0

This is the first stable release. Install it with:

```bash
composer require liberusoftware/theme-real-estate-default
```

The theme inherits `default`, so keep `liberusoftware/theme-default` installed. Use the
manifest and `THEME_*` host configuration to select it; do not edit installed files under
`themes/real-estate-default` directly.
