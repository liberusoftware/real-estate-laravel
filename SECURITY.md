# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's security advisory feature. Do not open public issues for security concerns.

## What to Expect

This project is maintained by volunteers and there is no guaranteed response time or service level agreement. We will do our best to address reported vulnerabilities in a timely manner.

## Scope

The following are in scope for security reports:

- `app/` application code
- `routes/` route definitions
- `database/` migrations and seeders
- `config/` configuration files
- `resources/` views and frontend assets
- API endpoints and authentication logic

## Out of Scope

The following are not in scope:

- Third-party dependencies (report to the respective upstream project)
- Issues requiring `APP_DEBUG=true` in production
- Social engineering or physical attacks
- Denial of service attacks against infrastructure

## Supported Versions

Security fixes are applied to the latest major version. Users are encouraged to upgrade to the most recent release.
